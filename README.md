# Extension Study Programmes Scientific Computing - 198718 VU C and C++ in Simulation Development

Repository for the "C and C++ in Simulation Development" course (198718) at the University of Innsbruck

Deployed slides: https://kandolfp.github.io/198718_ESP-SC_CPP/

## Installation
1. Install `quarto-cli` from https://quarto.org/docs/get-started/
2. Install the Quarto VS Code extension
3. Install `pdm` from https://pdm-project.org/en/latest/#recommended-installation-method
4. Create a `venv` with `pdm venv create` and activate it with `pmd use`
5. Install all packages with `pdm install`
