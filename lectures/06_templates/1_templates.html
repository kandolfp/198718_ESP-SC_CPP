Templates

In the session about object oriented programming we created a Matrix class where our data was of type double. What happens if we want to implement the same class with values in float and complex?

  • We need to create the same class and methods again, just change the data type
  • A lot of copy past code.
  • Hard to maintain as we have duplicates in multiple locations.
  • We have already used templates with the std::vector class but did not talk about it.

Our first example: We want to get the maximum of elements of different types like int, double, char, what is the code for that?

Templates - C++ - a first example

Can we compile the following code what will be the output?

Code file template_easy_start.cpp

// g++ -std=c++17 -o main.out template_easy_start.cpp 
#include <iostream>

template <typename T> T myMax(T x, T y) { return (x > y) ? x : y; }

int main() {

  std::cout << "Max of 7 and 3 is: " << myMax<int>(7, 3) << std::endl;
  std::cout << "Max of 3.5 and 7.5 is :" << myMax<double>(3.5, 7.5)
            << std::endl;
  std::cout << "Max of 'e' and 'g' is: " << myMax<char>('e', 'g') << std::endl;

  return 0;
}

Templates - C++ - argument detection since C++17

Since C++17 we can even skip specifying the type and it is detected automatically.

Templates - C++ - Where can we apply this technique?

We can crate templates for

  • functions
  • classes
  • variables (since c++14)

and we can use multiple types if needed:

template <typename T1, typename T2, typename T3> class Test
{
  public:
    T1 x;
    T2 y;
    T3 z;
}

Templates - C++ - variable template since C++14

Code file template_variable.cpp

// g++ -std=c++17 -o main.out template_variable.cpp
#include <iomanip>
#include <iostream>

template <typename T>
constexpr T pi = T(3.141592653589793238462643383279502884197169399);

int main() {
  // Using pi with different types
  std::cout << std::setprecision(64) << "Pi as float: \t\t"
            << pi<float> << std::endl
            << "Pi as double: \t\t" << pi<double> << std::endl
            << "Pi as long double: \t" << pi<long double> << std::endl;
  return 0;
}

Templates - C++ - Good to know

There are a couple of additional things for templates that are good to know

  • We can specify default templates

    template <typename T1, typename T2=double, typename T3=string> class Test

  • We can mix template and normal arguments in a signature

    template <class T, int max> int arrMin(T arr[], int n)

  • What happens if we try to compile the following fragment?

    std::cout << "Max of 7 and 3.0 is: " << myMax(7, 3.0) << std::endl;

Templates - C++ - metaprogramming

It is possible to do metaprogramming with templates and therefore use templates to compute something during compile time. It heavily depends on recursion

Code file template_meta.cpp

#include <iostream>

// Template metaprogramming for calculationg factorial at compile-time
template <int N> struct Factorial {
  static const int value = N * Factorial<N - 1>::value;
};

// Specialization for the base class (Factorial<0>)
template <> struct Factorial<0> {
  static const int value = 1;
};

int main() {

  // Factorial computation happens at compile-time
  std::cout << "Factorial of 5 is: " << Factorial<5>::value << std::endl;

  return 0;
}
Factorial of 5 is: 120
