A simple stencil code

Python

for i in np.arange(1, N - 1):
  for j in np.arange(1, N - 1):
      out[j + i * N] = inn[j + i * N] \
                     + alpha * (inn[j - 1 + i * N] - 
                               2.0 * inn[j + i * N] + inn[j + 1 + i * N])
Compile and Wall time (2nd order):  7.65 s (1.08 s with numba)
                                           (0.67 s with slicing)

C++

for(int i = 1; i < N-1; i++)
    for(int j = 1; j < N-1; j++)
        out[j + i * N] = in[j + i * N] 
                       + alpha * (in[j - 1 + i * N] - 
                                 2.0 * in[j + i * N] + in[j + 1 + i * N]);
Compile and Wall time (2nd order): 0.28 s

Performance implications

  • Drastic performance improvement (\(\approx 27\)x).

    • Reduces run time for your code.

  • Python is an interpreted language.

    • A program, the interpreter, reads the python code and executes one statement after another.

  • C++ is a compiled language that uses a two-step approach

    • Compilation: A program, the compiler, reads the C++ code and translates it into machine code.
    • Execution: The machine code is directly executed by the CPU.

🤓: In reality Python uses an intermediate representation (bytecode) and relies on compiled Fortran/C/C++ code.

What is compilation

Can we compile Python?

x = 3           # x is a integer
if condition:
    x = 3.0     # x is a floating point number
y = 2 * x
  • What operation should “2 * x” be compiled to?
    • integer/floating point multiplication
  • Compiler would need to understand all possible types that x can have.
    • For an interpreted language this is much simpler (can be decided during run time)
  • In C++ type information need to be specified at compile time.
    • Having type information available makes optimizing the machine code easier.

Performance part 2

Fourth order stencil in Python

for i in np.arange(1, N-1):
    for j in np.arange(1,N-1):
        out[j + i * N] = inn[j + i * N] + alpha * (
                -1./12. * inn[j - 2 + i * N] + 4./3. * inn[j - 1 + i * N] \
                - 5./2. * inn[j + i * N] + 4./3. * inn[j + 1 + i * N] \
                - 1./12. * inn[j + 2 + i * N]);
Compile and Wall time (2nd order):  7.65 s, (4th order):  11.84 s

Fourth order stencil in C++

for(int i=1; i < N-1; i++)
    for(int j=2;j < N-2; j++)
        out[j + i * N] = in[j + i * N] + alpha * (
            -1./12. * in[j - 2 + i * N] + 4./3. * in[j - 1 + i * N] \
            - 5./2. * in[j + i * N] + 4./3. * in[j + 1 + i * N] \
            - 1./12. * in[j + 2 + i * N]);
Compile and Wall time (2nd order): 0.28 s, (4th order): 0.28 s

Performance and use of the language

In Python using the second order method is \(1.5\)x faster than fourth order method. In C++ the second and fourth order methods take the same time.

  • Performance is often limited by fetching data from memory and not by the number of arithmetic operations the CPU can perform. This is called a .

Writing Python code to predict the performance of a C++ code is a bad idea!

Why is Python used?: Many software packages have embraced a high-level Python interface.

Python is often used to specify the problem but all the heavy lifting is done under the hood is usually in C++.

Makes the software approachable for users while maintaining good performance.

Hello World! in C++

Let’s start with hello_world.cpp

#include <iostream> // include dependencies; header files of libraries

int main() { // the main function is called when executing the code
  std::cout << "Hello World!" << std::endl; // print "Hello World!"
  return 0;                                 // return terminates the program
}
Hello World!
  • comments are added by // comment
  • start by including libraries (iostream for printing output)
  • main instructions inside int main(){ program code }
  • print output by std::cout << "...", end line with std::endl
  • every command must be ended with ;
  • end program with return 0; (exit as intended, with no errors)

Compiling code

To compile the code we run the following code in the terminal

$ g++ -o hello.out main.cpp

The compiler g++ goes through your source code to

  • check if the code has the correct syntax

  • translate the code into instructions readable by the computer

  • generates the executable `hello.out} which you can run with

    $ ./hello.out

Types

What are types and why do we need them?

Number representation 1/2

  • Numbers are represented by bits.
  • Integers usually use \(16\) bits (\(-32768\) to \(32767\))

Number representation 2/2

  • Real numbers: sign \(\cdot\) mantissa \(\cdot\ 2^\text{exponent}\)
  • double uses \(64\) bits

What are types and why do we need them?

  • Whenever possible, we would like to tell the program how many bits we need.

  • Remember that the C++ compiler requires us to define the type in advance

    x = 3 # x is a integer
if condition:
  x = 3.0 # x is a floating point number
y = 2 * x

  • Types simplify readability.

  • Main types are: char, string, int, long, float, double

Code example

Code file main_typer.cpp

int main() {
  int i;          // declaration
  i = 2;          // definition
  float d = 2.3f; // declaration and definition
  double a = 1.0, b = 2.3;
  return 0;
}
  • From the code, the compiler knows that \(16\) bit are needed for i, \(32\) bit for d, and \(64\) for a and b.
  • It is good practice to declare variables at the beginning of the code.

The compiler and linker

Compiler and linker basics

  • We write code that humans understand but computers can’t → translation into machine language

  • The main tools are the compiler and the linker.

  • Compiler: C++ code into machine language file (object file, main.o, main.obj)

  • Linker: combine obj files and libraries (precompiled code)

    $ g++ -c hello.cpp
$ g++ -o hello.out hello.o
$ ls
hello.cpp  hello.o  hello.out

    We will revisit the compiler multiple times once our programs become more complicated.

Basic programming concepts

We need some conditionals and loops

Conditionals

C/C++ comes with the basic conditionals: if, else if, else

if ( boolean == true ){
    // statement executed if the condition boolean == true is valid
} else if (boolean1 == true){
    // statement executed if the condition boolean == true is not valid but boolean1 == true
} else{
    // statement executed if both conditions are false
}

New variables defined inside these environments are unknown to the global scope.

Loops

C/C++ comes with the basic loops: for, while, do while

for ( long i = 0; i < 10; i++ ){
   // statement
}

while ( boolean == true ){
   // statement
}
    
do {
  // statement
} while( boolean == true )

To exit a loop early we can use break and continue to jup along

Range based loops

The range based of often also called for each loop is available in C++ as well

std::vector<int> numbers = {1, 2, 3, 4, 5};

// Range-based for loop
for (int num : numbers) {
    std::cout << num << " ";
}

// Range-based for loop with auto key word
for (auto num : numbers) {
    std::cout << num << " ";
}
