Classes

Classes can be seen as fancy structs which are equipped with

  • constructors that take care of initialization
  • destructors that take care of deletion
  • (copy) operations
  • functions that operate on the data (methods)
  • hierarchies
  • protection of variables and functions
  • \(\ldots\)

Classes - Syntax

class class_name{
private:
  // private variables and functions
public:
  // public variables and functions
};

Example:

class Entry {
private:
  long _data;
  Entry *_next;
  Entry *_previous;

public:
  Entry(long data) : _data(data) {}
};

In C++ the only difference between struct and class is whether data is public or private by default.

  • private data/functions are protected from modification
  • public data/functions are accessible
  • note that the Print function can access private data

Data management 1/2

class Entry {
  double *_data;

public:
  Entry(double data) : _data(new double) { *_data = data; }
};

int main() {
  if (true)
    Entry tmp(1);
  return 0;
}
  • What behaviour do you expect?
  • Dynamic memory will not be deleted by default. This has to be done via the destructor.

Data management

class Entry {
  double *_data;

public:
  Entry(double data) : _data(new double) { *_data = data; }
  ~Entry() { delete _data; }
};

int main() {
  if (true)
    Entry tmp(1);
  return 0;
}
  • What behaviour do you expect?
  • Dynamic memory will not be deleted by default. This has to be done via the destructor.
  • Usually an object which allocates dynamic memory is responsible for deallocating it.

Copy constructor 1/3

Code file main_copy.cpp

#include <iostream>

class A {
public:
  double *_d;
  A(double d) : _d(new double) { *_d = d; }
  ~A() { delete _d; }
};

void foo(A aFoo) {}

int main() {
  A a(1.234);
  foo(a);
  std::cout << *a._d << std::endl;
}
1.13948e-313

Copy constructor 2/3

  • Function foo creates a new object aFoo and copies all values from a.
  • We did not specify how this new class A is copied!
  • By default all variables are simply copied. I.e., aFoo._d = a._d.
  • aFoo is deallocated when leaving function (static memory!)
  • Destructor of aFoo deallocates aFoo._d and thereby a._d.
  • Good thing we understand pointers ;)

Way out: Define our own copy constructor.

Copy constructor 3/3

Code file main_copy2.cpp

#include <iostream>

class A {
public:
  double *_d;
  A(double d) : _d(new double) { *_d = d; }
  A(const A &a) {
    _d = new double;
    *_d = *a._d;
  }
  ~A() { delete _d; }
};
void foo(A a) {} // calls copy constructor

int main() {
  A a(1.234);
  if (true)
    A b(a); // calls copy constructor
  foo(a);
  std::cout << *a._d << std::endl;
}
1.234

Summary

Classes can be used to group data and operations on them.

  • More in object oriented programming
  • This helps to structure code.

But if dynamic memory is used there can be issues.

  • Managed via constructors and destructors.
  • This is how std::vector is implemented.

For your own code consider using std::vector and other higher-level classes that have allocation and deallocation already figured out .
