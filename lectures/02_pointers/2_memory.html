Memory management

🎯 Learning goals of this course

  • Understand memory management

Why?

  • Pointers give control over memory.
  • Pass data to a different program part without copying it (functions, classes,…).
  • Control when to delete data dynamic vs. static memory.
  • static memory managed by compiler (stack)
  • dynamic memory managed by user (heap)
  • dynamic memory can be accessed with pointers (stored in stack)
  • address space in heap is accessed with new

Some code examples 1/2

Code file main_heap1.cpp

#include <iostream>

int main() {
  double dStatic = 0.1;
  double *dDynamic = new double; // allocate memory in heap
  *dDynamic = 0.1;

  std::cout << dStatic << " " << *dDynamic << std::endl;

  delete dDynamic; // free memory

  std::cout << dStatic << " " << *dDynamic << std::endl;

  return 0;
}

Some code examples 2/2

Code file main_heap2.cpp

#include <iostream>

int main() {
  double *v = new double[2]; // allocate array of size 2 in heap
  v[0] = 0.1;
  v[1] = 0.12;

  for (int i = 0; i < 2; i++)
    std::cout << v[i] << " ";
  std::cout << std::endl;

  delete[] v; // free memory of entire array

  return 0;
}
0.1 0.12

An array in heap

  • We store address of v[0] in v.
  • Since v[1], \(\ldots\) neighbour v[0] we also know their addresses.
  • More about this when talking about pointer arithmetic.

Multi-dimensional arrays

In the C/C++ standard there is no dynamic multi-dimensional array.

  1. option: Use a pointer to a pointer.
    • Access via a[i][j].
      • Not very good memory layout on modern computer architectures (pointer chasing).
  2. option: Use an one-dimensional array and do the index calculations by hand.
    • Access via a[i + j*n].
  3. option: Use an external library that implements 2d arrays.
    • Access is usually provided by a(i, j)

Pointer arithmetics

  • Arithmetics on pointers allowed.
  • d[i] equivalent to *(d + i)

Code file main_arithmetics1.cpp

#include <iostream>

int main() {
  double *d;
  d = new double[4];
  d[0] = 0.0;
  d[1] = 0.1;
  d[2] = 0.2;

  std::cout << *d << " " << *(d + 1) << std::endl;

  return 0;
}
